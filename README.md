# Орбітальна станція – веб-тренажер з Python (розгалуження й цикли)

Тренажер до магістерської роботи «Методичні особливості вивчення керуючих конструкцій мови програмування Python у шкільному курсі інформатики».

- 6 рівнів (проста умова → if-else → elif і складені умови → for → while → break, continue, вкладені цикли), 56 завдань.
- 7 типів вправ: передбач результат, трасування, пошук помилки, складання коду з рядків, доповнення коду, створення програми, місія.
- Python виконується просто в браузері (Pyodide), нічого встановлювати не треба. Перше завантаження – до 1 хвилини, далі браузер бере файли з кешу.
- Автоматична перевірка за тестами (з прихованими тестами на граничні значення), захист від нескінченних циклів, підказки після 2 і 4 невдалих спроб, відзнаки, правило відкриття рівнів.
- Журнал спроб надсилається в Google-таблицю вчителя; є панель учителя (`teacher.html`).

## Структура

| Файл / тека | Призначення |
|---|---|
| `index.html` | тренажер для учнів |
| `teacher.html` | панель учителя |
| `js/tasks.js` | рівні та завдання (тут можна редагувати тексти, тести, підказки) |
| `js/config.js` | налаштування: адреса Google-таблиці (`REPORT_URL`), обмеження часу |
| `js/app.js`, `js/worker.js`, `css/style.css` | код тренажера |
| `pyodide/` | інтерпретатор Python для браузера (Pyodide 0.27.7) |
| `start-local.bat`, `start-local.ps1` | локальний сервер для перевірки на Windows |
| `apps-script/Code.gs` | скрипт для Google-таблиці (на GitHub завантажувати не обов’язково) |

## 0. Перевірка на своєму комп’ютері (перед розміщенням в інтернеті)

**Не відкривайте `index.html` подвійним клацанням**: адреса тоді починається з `file://`, і браузер блокує запуск Python – перевірка не працюватиме.

- **Windows:** двічі клацніть `start-local.bat` – відкриється вікно сервера і браузер з адресою `http://localhost:8000/index.html`. Поки тренажер потрібен, вікно сервера не закривайте.
- **Якщо встановлено Python:** у теці тренажера виконайте `python -m http.server 8000` і відкрийте `http://localhost:8000`.

Для уроків використовуйте адресу на GitHub Pages (розділ 1).

## 1. Розміщення на GitHub Pages (≈10 хв)

1. Зареєструйтеся або увійдіть на https://github.com.
2. Натисніть **New repository**. Назва, наприклад, `orbita`, тип **Public**. Натисніть **Create repository**.
3. На сторінці репозиторію: **Add file → Upload files**. Перетягніть **усі файли й теки з архіву** (`index.html`, `teacher.html`, теки `css`, `js`, `pyodide`, `apps-script`, `README.md`). Натисніть **Commit changes**.
4. **Settings → Pages**: у полі *Branch* оберіть `main` і теку `/ (root)`, натисніть **Save**.
5. Через 1–2 хвилини тренажер буде доступний за адресою `https://ВАШ-ЛОГІН.github.io/orbita/`.

## 2. Підключення Google-таблиці (≈5 хв)

1. Створіть нову Google-таблицю (наприклад, «Орбіта – журнал»).
2. **Розширення → Apps Script**. Видаліть вміст файлу `Code.gs` і вставте вміст файлу `apps-script/Code.gs` з архіву.
3. У рядку `const TEACHER_KEY = 'змініть-цей-ключ';` придумайте власний ключ (його вводитимете в панелі вчителя).
4. **Розгорнути → Нове розгортання → тип «Веб-застосунок»**: «Виконувати від імені» – **Я**; «Хто має доступ» – **Усі**. Натисніть **Розгорнути** і дозвольте доступ до таблиці.
5. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`).
6. У файлі `js/config.js` вставте цю адресу: `REPORT_URL: 'https://script.google.com/macros/s/…/exec',` і завантажте змінений `config.js` на GitHub (Add file → Upload files, із заміною).

Після цього кожна перевірка завдання з’являтиметься рядком на аркуші **«Спроби»**: час, клас, код учня, рівень, завдання, тип вправи, результат, тип помилки, номер спроби, кількість підказок, час на завданні. Ці дані знадобляться для розділу 3 (апробація).

Якщо інтернет у класі зникне, тренажер збереже записи в браузері й надішле їх пізніше.

## 3. Посилання для класів

- 7 клас (рівні відкриваються за правилом методики): `https://ВАШ-ЛОГІН.github.io/orbita/?cls=7-А`
- 8–9 класи (одразу відкриті всі рівні): `https://ВАШ-ЛОГІН.github.io/orbita/?open=all&cls=8-Б`
- Відкрити рівні 1–3: `?open=3`
- Панель учителя: `https://ВАШ-ЛОГІН.github.io/orbita/teacher.html` (ключ – той, що в `Code.gs`).

Учні вводять клас і **код учасника** (номер у списку або псевдонім), без прізвищ. Прогрес зберігається в браузері: на тому самому комп’ютері учень продовжує з того місця, де зупинився.

## 4. Як змінити завдання

Усі завдання – у `js/tasks.js`. Для кожного: текст умови (`text`), тести (`tests`: `in` – вхідні дані, `out` – очікуваний вивід, `hidden` – прихований тест, `why` – пояснення при невдачі), дві підказки (`hints`). Для вправи «складання з рядків» рядки записуються вже в перемішаному порядку.
